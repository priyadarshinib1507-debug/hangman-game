# Hangman Game (Python)

This is a simple text-based Hangman game developed using Python.

## Features
- Random word selection
- 6 maximum incorrect attempts
- User input for guessing letters

## Concepts Used
- Lists
- Strings
- Loops
- Conditional statements
- Random module

## How to Run
1. Open the file in Python
2. Run the program
3. Start guessing letters
